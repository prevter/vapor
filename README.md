# vapor

Steam DRM remover mod for Geometry Dash.

## About

Unlike Goldberg Emulator, this mod completely disables Steam initialization step,
which is more efficient than emulating it. Works on all Steam-supported platforms:
- Windows
- Linux with Wine/Proton
- macOS (both ARM and Intel-based)
